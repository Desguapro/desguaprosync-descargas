# DesguaProSync — descargas

Instalables de DesguaProSync, la app de fotos de [DesguaPro](https://desguapro.com) para el taller.

En la sección **Releases** está siempre la última versión:

- `DesguaProSync.exe` — el programa del ordenador (Windows). Se copia a una carpeta y se abre con doble clic.
- `DesguaProSync.apk` — la app del móvil (Android).

Una vez instalados se actualizan solos: el programa del ordenador busca aquí cada versión nueva y se la ofrece a los móviles de su red.

Para usarlos hace falta una cuenta de DesguaPro de una empresa activa.
